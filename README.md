# Personal AI Agent

A secure, modular personal AI assistant that acts as your personal operating system.

## Features

- **Gmail Integration** - Read, summarize, and draft emails
- **SMS Notifications** - Send text messages for important updates
- **Voice Calls** - Initiate calls for urgent situations
- **Memory** - Long-term memory about you, your projects, and relationships
- **Approval Workflow** - High-risk actions require your approval
- **Complete Audit Logging** - Every action logged for security

## Quick Start

1. Clone the repository
2. Copy `.env.example` to `.env` and fill in your credentials
3. Run `npm install`
4. Run `npm start`
